# MF-Log

Installierbare Web-App (PWA) für ein persönliches Trainings- und Symptomprotokoll.

- App: https://patisgay.github.io/mf-log/app/
- Testkanal mit Beispieldaten: https://patisgay.github.io/mf-test/ (eigenes Repo PatIsGay/mf-test)

Alle Einträge bleiben auf dem Gerät (Browser-Speicher). Dieses Repo enthält nur die ausgelieferten Dateien, keine Nutzerdaten. Die Dateien werden automatisch aus einem privaten Entwicklungs-Repo hierher kopiert; Änderungen bitte nicht direkt hier vornehmen.
